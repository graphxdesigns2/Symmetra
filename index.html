Controls & Navigation Guide

Shortcuts, mouse navigation, live editing, and sync features

Block Navigation

↑ ↓
Step Blocks: Jump forward or backward one synchronized block at a time.
Wheel
Mouse Wheel: 1 mouse wheel notch moves down or up exactly 1 block without skipping.
Click
Direct Selection: Click any block in either English or French preview to instantly jump and align.
HUD
Block Stepper / Jump: Click the "Block X/Y" badge in the bottom bar to type a number and jump directly.

Sync & Offset Control

Alt
Pause Sync: Hold Alt while scrolling or clicking to freely navigate one pane independently without moving the other.
[ ]
Nudge Alignment: Shift the French pane's alignment offset by -1 or +1 block if paragraphs are misaligned.
Auto-Sync
Toggle Synchronization: Enable or disable dual-pane locked scrolling from the view control bar.
− 0 +
Reset Sync: Click the offset value in the middle of the sync stepper to clear any manual offset and re-synchronize the active block to parity.

Live Localization & Export

Visual
Live Visual Editing: French text is editable live in the preview. Click into any text block and type directly.
Code
Code View: Switch to Code View in the French header to copy and inspect clean localized HTML.
Ctrl + +/-
Magnifier: Zoom in and out of the compare screens using the toolbar magnifier, Ctrl + +/-, or Ctrl + wheel. Buttons and UI remain fixed.
Focus
Focus & Blur: Use Focus Mode or Blur Inactive to spotlight the current block and eliminate distractions.
Esc ?
Quick Keys: Press ? to toggle this guide, and Esc to close any active drawer or modal.
N Shift+N
Issue Hopping: Press N to jump to the next QA issue (Missing, Mismatch, QA Diff, Spacing, lang="en", Extra) and Shift+N to go back.
Tip: Reopen this guide anytime from the top bar or by pressing ?.
